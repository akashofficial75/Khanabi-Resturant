
🍔 Khanabi — Premium Fast Food Restaurant Website

A modern cinematic restaurant website built with a luxury dark aesthetic, smooth animations, interactive UI, and fully responsive design. This project features premium food showcases, animated loading screens, glowing social icons, dynamic food sections, and a complete modern fast-food branding experience inspired by international restaurant websites.

Designed to deliver a visually engaging and mouth-watering user experience with modern web technologies and smooth performance across all devices.

* Premium Dark UI/UX
* Responsive Design
* Animated Food Showcase
* Interactive Components
* Modern Loading Screen
* Smooth Transitions & Hover Effects
* Social Media Integration
* Professional Restaurant Branding
